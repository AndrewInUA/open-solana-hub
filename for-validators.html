For validators

Validator alerts for the operator who runs the machine.

Paste a vote account, then a name for yourself. For testnet, put the word testnet first. The bot watches that vote account and messages this chat when something an operator acts on has changed. Public data only. It never asks for a seed or a key.

What it messages

  • One message when voting stops, with the reason the public network can show. One message when it votes again.
  • The Foundation version list, and how long until a higher floor starts. The line ends with a link to the official list. Check says when the client already meets every published floor.
  • The address the node is announcing, so you can see which machine is live.
  • Balance notes are off until you turn them on. Then a change in the vote-account balance is its own note.

What the buttons do

  • Check reads the watch now.
  • Watches lists what this chat is watching.
  • Add asks for a vote account and a name. Send the same vote account with a new name to rename it.
  • Remove drops one watch, or all of them.
  • Help repeats this.
